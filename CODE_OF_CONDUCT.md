# Codice di condotta

Chi partecipa a issue, pull request e altre discussioni del progetto è invitato a mantenere un ambiente rispettoso e accessibile.

- Usare un linguaggio cortese e discutere le proposte sulla base di fatti ed esempi.
- Accogliere domande e contributi anche di chi ha poca esperienza tecnica.
- Evitare insulti, molestie, discriminazioni, minacce e contenuti sessuali non pertinenti.
- Non pubblicare dati personali di altre persone senza il loro consenso.
- Rispettare le richieste di interrompere un comportamento o una conversazione.

Per segnalare un comportamento problematico, contattare il maintainer tramite i canali privati eventualmente indicati sul [profilo GitHub di GiorgioOppo](https://github.com/GiorgioOppo). Se non è disponibile un canale privato, è possibile aprire una [issue](https://github.com/GiorgioOppo/firenze-pulizia-strade/issues) per richiedere un contatto, senza pubblicare informazioni personali o dettagli sensibili.

Il maintainer valuterà il contesto e potrà chiedere una correzione, rimuovere contenuti, chiudere discussioni o limitare la partecipazione al progetto. Le misure saranno proporzionate alla gravità e all'eventuale ripetizione del comportamento.
